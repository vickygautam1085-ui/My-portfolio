# Student Management System 🎓

A simple Student Management System built using Python.

## 📌 About the Project

This project allows users to manage student information
through a simple command-line interface.

## 🚀 Features

- Add a new student
- Store student name and marks
- Display student records
- Search student records
- Handle invalid marks using error handling

## 🛠️ Technologies Used

- Python
- Lists
- Dictionaries
- Functions
- Loops
- Conditional Statements
- Exception Handling

## ▶️ How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder.
4. Run:

```bash
python "Student management system2.py"
